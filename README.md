# Innovartus Cloud Task Manager

A simple cloud-hosted Software as a Service application developed for the Innovartus Technologies Cloud Computing case study.

## Features

- Create tasks
- Assign task priorities
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Display task statistics
- Store tasks in browser local storage
- Responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- Vercel

## Cloud and DevOps Features

- Source-code version control with GitHub
- Cloud deployment with Vercel
- Automatic deployment through CI/CD
- Deployment and error monitoring
